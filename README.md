# OSK 返老还童验证项目（osk-rejuvenation）

## 一句话目标
验证"表观遗传部分重编程（OSK / ER-100）能否在人体中让视野功能改善与细胞生物学年轻化同时对上"，用可证伪判据在 2–3 年内给出**成 / 凉 / 存疑**的终判。

## 为什么立这个项目（决策依据）
在"真永生"三条技术路线里做选择：
- **路线 A 生物修复**（同一肉身，"我"连续）—— 选它的 **A1 分支：表观遗传部分重编程**。
- 路线 B 全脑仿真 / 意识上传 —— 弃选：数据才是瓶颈，中位预测 2068–2088，且复制≠"我"。
- 路线 C 渐进替换 —— 弃选：纯概念，无实验路径。

选定 A1 的唯一硬理由：**它是三条路线里唯一在近期（2–3 年）能给出可证伪读数的**。信息增益 ÷ 等待时间最高。它不是"无限寿命"，而是"把衰老变成可治的病"这条路上第一个能拿到清晰读数的技术。

## 核心判据（verifier，先看这里）
见 [verifier.md](verifier.md)。一句话版：
- **成了**：随机对照下视野改善 + 疗效持续 + 细胞年轻化指标同现。
- **凉了**：安慰剂组同样改善 / 随访回退 / 致瘤或去分化安全信号。
- 2026-10-08 首批 3 人数据不触发任一判据（无对照、最低剂量、8 周、未证细胞年轻化）。

## 数据来源与可信度
见 [literature/evidence-base.md](literature/evidence-base.md)。所有数字带 URL 与可信度标注：
- 同行评议（A/B）与公司自述（C）严格分开。BioViva/BioViva 式单人自述、pay-to-play 数据**不作证据**。
- 复核纪律：同一事实最多两种独立方式、两次复核；查不到就停并标注，不无限重搜。

## 运行 / 推进方式
本项目是**桌面研究 + 试验读出跟踪**型，不自行开展人体或动物实验：
1. 监控 NCT07290244（ER-100，青光眼 + NAION）的公开读出与 Life Biosciences 公告。
2. 每有新读出，按对应实验 design.md 的判据更新 `research-manifest.json`（loop/experiments/hypotheses 状态）与 verifier 判定栏。
3. 里程碑 M2/M3/M4 达标时给出终判，写入 `reviews/`。
